# twconnects.org — Tanisha Washington Connections

Static export of the TW Connects mission site ("Empower. Invest. Elevate."),
moved off Hostinger website-builder hosting to GitHub Pages, September 2026.

- Pages: Home (`/`), Mission (`/mission`), Programs (`/programs`), Donate (`/donate`)
- All images and fonts are vendored under `assets/` — no dependency on the
  builder CDN except the Zyro `traffic.txt` analytics beacon and stock
  photo/video hotlinks (Unsplash, Pexels).
- Custom domain: `twconnects.org` (see `CNAME`; DNS points at GitHub Pages).

Owner: Tanisha Washington. Staged under marchitectsio pending transfer to
Tanisha's own GitHub account.
